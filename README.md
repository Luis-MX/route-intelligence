# route-intelligence

## Descripción

Este proyecto aborda la gestión de interrupciones durante la ejecución de rutas de reparto de paquetes. El problema parte de una planeación de rutas sujeta a restricciones operativas y considera eventos que pueden volver subóptima o inviable la solución originalmente calculada.

Se explorarán técnicas de inteligencia artificial en combinación con métodos de optimización para acelerar, guiar o mejorar la generación de soluciones ante estos cambios inesperados.

## Dominio de aplicación

Optimización y apoyo a la toma de decisiones.

## Herramientas previstas

- Python
- Scikit-learn
- PyTorch
- Herramientas de optimización por definir con el asesor

## Estructura del repositorio

- `data/`: datos simulados y documentación sobre su origen y estructura.
- `notebooks/`: análisis, experimentación y pruebas.
- `docs/`: entregables, referencias y documentación metodológica.
- `src/`: código reutilizable para simulación, optimización y modelos de IA.
- `results/`: resultados experimentales, tablas y figuras.
