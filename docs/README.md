# Documentación del proyecto

Esta carpeta reúne los entregables y materiales técnicos del Proyecto Integrador *Planeación de rutas con interrupciones*, desarrollado por el Equipo 42 de la Maestría en Inteligencia Artificial Aplicada del Tecnológico de Monterrey.

## Entregables académicos

Los materiales se encuentran organizados cronológicamente en la carpeta [entregas](entregas/), con un directorio para cada uno de los ocho avances del proyecto.

## Documentos principales

- [Artículo académico](entregas/avance-7-proyecto-de-difusion/articulo_academico.pdf): metodología, evaluación y resultados experimentales.
- [Resumen ejecutivo](entregas/avance-7-proyecto-de-difusion/resumen_ejecutivo.pdf): síntesis del trabajo y consideraciones para su aplicación.
- [Póster del Proyecto Integrador](entregas/avance-8-poster-y-cierre/poster.pdf): presentación visual de los procedimientos y principales resultados.

Para consultar la descripción general del proyecto, véase el [README principal](../README.md).
