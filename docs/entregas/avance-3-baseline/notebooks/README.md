Las notebooks incluidas corresponden a los experimentos del Avance 3 del Proyecto Integrador.

La Notebook 2 utiliza los archivos derivados de la Notebook 1. Ambas se conservan con los resultados obtenidos durante el desarrollo del avance. Para reproducirlas es necesario configurar las rutas y disponer de los datos correspondientes.
