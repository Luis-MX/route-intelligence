## Descripción

Este avance construye y evalúa un baseline histórico para estimar matrices de tiempos de desplazamiento en el escenario K=0, sin disponer de observaciones actuales de tiempos de recorrido. Se utiliza una red experimental derivada de PEMS-BAY y se comparan distintas referencias históricas, seleccionando la especificación mediante validación temporal y evaluándola sobre un periodo posterior de prueba.

## Organización

La Notebook 1 prepara los datos y construye la red experimental. La Notebook 2 utiliza los datos derivados para generar las matrices origen-destino y evaluar el baseline. Las libretas incluidas corresponden a las versiones utilizadas en esta entrega.
