
# Fuentes del resumen ejecutivo

Este directorio contiene los archivos fuente del resumen ejecutivo del Avance 7.

El documento se prepara en LaTeX y puede compilarse con pdfLaTeX en Overleaf.

Archivos:
- `resumen_ejecutivo.tex`: documento principal.
- `logo.jpeg`: logotipo utilizado en el encabezado.

El PDF final se encuentra en la carpeta principal del Avance 7.
