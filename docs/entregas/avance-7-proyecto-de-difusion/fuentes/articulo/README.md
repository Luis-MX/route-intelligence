# Fuentes del artículo académico

Este directorio contiene los archivos fuente utilizados para compilar el artículo *Estimación y pronóstico de tiempos de viaje en redes dirigidas*.

Se incluyen el documento principal en LaTeX, los archivos bibliográficos y las figuras empleadas en el artículo.

Para reproducir el PDF, se recomienda utilizar Overleaf, con `articulo_Equipo42.tex` como archivo principal y Biber para procesar las referencias bibliográficas.

Los resultados experimentales y los cuadernos que los respaldan se encuentran documentados en las entregas técnicas del proyecto.
